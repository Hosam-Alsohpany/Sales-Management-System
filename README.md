🛒 نظام إدارة المبيعات

📋 ملخص المشروع (Project Summary)

نظام إدارة مبيعات ومخزون هو تطبيق مكتبي مبني باستخدام C# Windows Forms و SQLite، يهدف إلى تنظيم عمليات البيع والشراء وإدارة المنتجات والعملاء والموردين والمخزون والمدفوعات والتقارير من خلال نظام واحد.
تم تصميم النظام ليعمل محليًا على أجهزة Windows، حيث يتم إنشاء قاعدة البيانات تلقائيًا عند تشغيل النظام لأول مرة دون الحاجة إلى خادم قاعدة بيانات خارجي.

🚧 المشروع قيد التطوير

المشروع غير مكتمل بالكامل وما زال قيد التطوير، ويتم مشاركته على GitHub لعرض العمل المنجز حتى الآن ضمن Portfolio لمطور C#.

🧱 أنماط التصميم المستخدمة
•	Repository Pattern — لفصل الوصول إلى البيانات.
•	Service Layer — لفصل منطق الأعمال عن الواجهة.
•	Migration Pattern — لإدارة تطور قاعدة البيانات.
•	Strategy Pattern — في معالجة بعض عمليات الباركود.
•	Pipeline Pattern — في معالجة الباركود.
•	Session Manager — لإدارة جلسة المستخدم والصلاحيات.

🗄 قاعدة البيانات
يستخدم النظام SQLite كقاعدة بيانات محلية، ولا يحتاج إلى SQL Server أو خادم قاعدة بيانات خارجي.
يتم إنشاء قاعدة البيانات تلقائيًا عند أول تشغيل بواسطة:
DatabaseInitializer.Initialize()
ويتم حفظ قاعدة البيانات في:
%AppData%\SalesApp\DataBase.db
ولا يتم رفع ملف قاعدة البيانات إلى GitHub.

⚙️ إعداد المشروع
1.	افتح ملف:
Sales.sln
باستخدام Visual Studio.
2.	قم باستعادة حزم NuGet.
3.	تأكد من وجود المرجع:
libs/System.Data.SQLite.dll
4.	قم ببناء المشروع من:
Build → Build Solution
5.	شغّل المشروع باستخدام:
F5
6.	عند التشغيل الأول، أكمل خطوات معالج الإعداد.
